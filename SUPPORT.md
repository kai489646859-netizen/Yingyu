# Support

Use the right channel so reports remain actionable:

- **Bug:** choose the Android or Windows Issue form.
- **Feature request:** choose the feature request form.
- **Usage question or compatibility discussion:** use GitHub Discussions.
- **Security or credential exposure:** follow [`SECURITY.md`](SECURITY.md), never a public Issue.

Before reporting a playback problem, record the platform/version, system or device, Emby Server version, media source type, relevant codec/container information, exact steps and approximate time of failure. Attach only a manually reviewed, redacted log.

Support is best effort. Compatibility can vary with server behavior, reverse proxies, Range/redirect support, network throughput, media structure, device decoders, GPU drivers and displays.
