# Yingyu Android 2.1.3 / code242

本次正式版汇总 1.9.6 之后最终仍然保留的功能与修复；已撤回或被后续方案替代的中间调整不列入。

## 主要变化

- 增加影片多版本选择、跨已保存账号的影视搜索、底栏直接拖动交互、可选人声增强和更完整的设备信息。
- 改善 Wi-Fi/移动数据切换及可靠文件的短暂断流续读，修复部分 302 和外挂字幕相对跳转改写签名地址的问题。
- 修复部分普通 50/60 帧影片在 1× 长播后的追赶不足；保留已经确认的 2× 基线及现有 3×、定位、字幕、缓存、HDR/杜比和原盘策略。
- 限制异常资料响应，修复底层命令失败资源泄漏、重复日志/状态任务积累，并加强 RTSP/HLS/DASH 与损坏媒体的解析安全检查。
- 修复搜索重试、异常评分、慢保存期间媒体库通知积压，以及并发字幕缓存总量可能超限的问题。

## 2.1.3 图片引用完整性修复

- 图片引用不再使用会按 8 MiB 窗口裁剪的普通日志存储，大媒体库可读取完整引用图。
- 修复引用压缩为空、写入中断、尾行/UTF-8/JSON 损坏和原子替换失败后仍可能误删缓存的问题。
- 引用记录不完整或保存失败时保守保留图片，待后续完整快照恢复；正常预算清理和用户主动清理语义不变。
- 已被旧版清空且没有其他副本的引用无法凭空恢复，后续正常媒体库同步可重新建立现有影视引用。

## 安装

下载 `Yingyu-2.1.3.apk` 后直接覆盖旧版。不要先卸载，以免本机账号、设置和缓存丢失。要求 Android 8.0 或更高版本。
