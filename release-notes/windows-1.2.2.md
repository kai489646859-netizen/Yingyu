# Yingyu Windows 1.2.2

本次正式版汇总 0.8.5 之后最终仍然保留的桌面功能与修复；已经撤回或被替代的中间方案不列入。

## 主要变化

- 完善“今日精选”五图轮播、首帧首页布局、主题切换、海报详情点击、账号切换后自动轮播和窗口启动恢复。
- 播放器增加本地字幕导入、指定时间跳转、服务端缩略图预览、季度/整季连续选集及有界跨季自动衔接。
- 控制栏按最终要求 3.5 秒隐藏；暂停/继续使用中央反馈，播放时显示暂停符号、暂停时显示播放符号。
- 区分真实 EOF、错误和停止等结束原因，避免可恢复 TLS 日志被直接当成播放终止。
- 弹幕支持哔哩哔哩、腾讯视频和爱奇艺公开来源，增加精选、显示区域、倍速平滑和连续编号国漫补查。
- 分集列表稍后到达并补齐当前集身份时，尚未匹配到来源的当前播放会自动重查。

完整累计说明见仓库中的 `CHANGELOG-Windows.md`。

## 安装

关闭正在运行的映屿，运行 `Yingyu-Setup-x64-1.2.2.exe` 覆盖安装。安装程序沿用既有应用身份和安装目录，不要求先卸载或清空账户、设置、进度和缓存。

Windows 安装包当前没有 Authenticode 数字签名，系统可能显示未知发布者或信誉提示。运行前请核对本页 SHA-256。

构建、静态核对、安装包完整性及实机使用测试已完成。
