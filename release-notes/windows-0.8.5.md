# Yingyu Windows 0.8.5

本次正式版汇总 0.5.8 之后最终仍然保留的桌面功能与修复；已撤回或被替代的界面实验不列入。

## 主要变化

- 主页面标题区与内容背景一体化，详情大图延伸到窗口顶部并随正文滚动；保留原生窗口按钮、拖动和播放行为。
- 首页采用左右不等宽双图布局，首帧即预留最终位置；推荐图片原位加载，下面内容不再等片单到达后突然下移。
- 改善随机推荐、缓存优先、同作品图片共享、缺图筛选、详情背景和演员图加载，同时保持账号隔离、限速与可见区调度。
- 设置页采用更紧凑的桌面布局；恢复并统一普通片单、继续观看、演员、详情和选集的尺寸与间距。
- 图片接口明确返回 HTTP 415 时可在原身份、认证和重定向边界内追加一次 JPEG 兼容请求；仍失败则保持真实空白。

## 0.8.5 修复

- 修复首页双图要等片单到达后才挂载的问题。
- 修复首页标题约 2 DIP 跳动的问题。
- 修复确认框请求尚未结束时可能重复弹出的问题。
- 修复滚动过程中延迟点击未取消、最终误打开详情的问题。

## 安装

关闭正在运行的映屿，运行 `Yingyu-Setup-x64-0.8.5.exe` 覆盖安装。安装程序沿用既有应用身份和安装目录，不要求先卸载或清空账户、设置、进度和缓存。

Windows 安装包当前没有 Authenticode 数字签名，系统可能显示未知发布者或信誉提示。运行前请核对同页 SHA-256。
