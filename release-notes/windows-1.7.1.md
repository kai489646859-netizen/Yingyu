# Yingyu Windows 1.7.1

| 平台 | 安装包 | 系统要求 |
| --- | --- | --- |
| Windows 安装版 | `Yingyu-Setup-x64-1.7.1.exe` | Windows 10/11，x64 |

本次正式版只汇总最终仍保留的功能与修复；中间开发版本不单独列出。

## 主要变化

- 切换分集时可直接从片头结束位置开始；继续观看补足同集时长，换服务器后精选封面按当前账号加载。
- 完善继续观看、完成状态、进度条、刷新回退、本机待同步和最近观看分集选择。
- 网络点播使用最多 5 GiB 前向磁盘缓存，并修复提前结束误判、时钟停滞、关闭释放与播放器输入问题。
- SDR、HDR10、HLG、HDR10+ 与杜比兼容输出按片源和显示能力协商；改善 HDR 转 SDR 高光、ICC 和跨屏色彩管理。
- 改善原盘首帧、定位预滚、双层流衔接、窗口光标、横图补图、资源标签、音轨文字和倍速弹幕。

完整累计说明见仓库中的 `CHANGELOG-Windows.md`。

## 安装

关闭正在运行的映屿，运行安装包覆盖安装。安装程序沿用既有应用身份和安装目录，不要求先卸载或清空账号、设置、进度和缓存。

安装包当前没有 Authenticode 数字签名，Windows 可能显示“未知发布者”或信誉提示。运行前请核对本页 SHA-256。
