# Yingyu Windows 1.3.4

本次正式版汇总 1.2.2 之后最终仍然保留的功能与修复；已经撤回或被替代的中间方案不列入。

## 主要变化

- 缩短首次弹幕匹配失败后的等待时间，多来源查询并行进行，降低部分剧集弹幕出现过晚的情况。
- 分段弹幕优先显示，完整弹幕在后台补齐并去重，改善弹幕数量偏少和加载不连续的问题。
- 优化连续编号、跨季和缺少集号媒体的分集识别，减少预告、总集篇或其他作品误匹配。
- 弹幕轨道已适配高密度场景：显示区域变化时优先在区域内重排，暂时无空轨道时短暂排队后再入场。
- 全屏与窗口切换时重新计算弹幕字号、位置和轨道；默认播放器窗口增大并保持合适比例。
- 保留首页轮播、选集定位、跨季连播、字幕工具、继续观看、中央播放状态反馈等累计功能。

完整累计说明见仓库中的 `CHANGELOG-Windows.md`。

## 安装

关闭正在运行的映屿，运行 `Yingyu-Setup-x64-1.3.4.exe` 覆盖安装。安装程序沿用既有应用身份和安装目录，不要求先卸载或清空账户、设置、进度和缓存。

Windows 安装包当前没有 Authenticode 数字签名，系统可能显示未知发布者或信誉提示。运行前请核对本页 SHA-256。

构建、静态核对、安装包完整性及实机使用测试已完成。
