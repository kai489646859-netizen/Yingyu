# Yingyu Windows 0.5.8

这是 Windows 平台首次公开归档，提供 x64 安装包以及与之对应的源码、调试符号和第三方许可资料。

## 主要功能

- 面向鼠标、键盘和桌面窗口适配的 Emby 媒体库、详情、季/集与内置播放界面。
- 深浅主题、海报墙、继续观看、原文件播放、音轨字幕、倍速、缓存和本地资料搜索。
- 片名、原名、演员及作品关系搜索，首次资料不足时沿用有界补齐机制。

## 0.5.8 修复

- 修复进入搜索页输入后仍停留在“猜你喜欢”、没有显示结果的问题。
- 打开搜索页后自动聚焦输入框；停止输入约 280ms 自动搜索，同时保留回车和搜索按钮。
- 快速改词、关闭或返回会取消过期任务，避免旧结果迟到覆盖当前页面。

## 安装

关闭正在运行的映屿，运行 `Yingyu-Setup-x64-0.5.8.exe` 覆盖安装。安装程序沿用既有应用身份和安装目录，不要求先卸载或清空账户、设置、进度和缓存。

## 验证与已知边界

本版已经过作者实机使用验证。浅色和深色各 81 项 WinUI/XBF 搜索流程检查及各 39 项侧栏/音量检查通过；安装包、托管 IL 与原生载荷也已核对。实机通过不代表所有 Windows、GPU、输入法、服务器和片源组合绝对无差异。
