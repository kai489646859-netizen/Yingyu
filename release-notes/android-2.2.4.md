# Yingyu Android 2.2.4 / code253

本次正式版汇总 2.1.3 之后最终仍然保留的功能与修复；已撤回或被后续方案替代的中间调整不列入。

## 主要变化

- 改善手机/平板选集菜单、搜索相关性、本地优先结果、跨季连播和异常分集保护。
- 电影、剧集与分集统一展示资源技术标签，保留基于实际媒体源 ID 的多版本选择。
- 增加公开弹幕匹配、精选弹幕、显示区域/字号/速度/时间偏移设置和本地 XML 导入。
- 分集资料晚到时，仅在同一媒体和当前会话边界内补齐身份并重查弹幕。
- 弹幕从画面边缘按媒体时间入场；设置变化和来源刷新不再截断已经在屏幕上的弹幕。
- 2×、3× 弹幕采用单向时钟和平滑校正；迟到的位置回报不会让弹幕前后跳动，真正定位仍独立重置，返回 1× 保持连续。

完整累计说明见仓库中的 `CHANGELOG-Android.md`。

## 安装

下载 `Yingyu-2.2.4.apk` 后直接覆盖旧版。不要先卸载，以免本机账号、设置和缓存丢失。要求 Android 8.0 或更高版本。
