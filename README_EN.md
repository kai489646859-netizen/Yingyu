# Yingyu

Yingyu is an independent Android and Windows client for user-provided Emby media libraries. It combines library browsing, search, watch state and in-app original-file playback.

| Platform | Current release | Requirement | Download |
| --- | --- | --- | --- |
| Android | 1.9.6 / code224 | Android 8.0+ | [Android release](https://github.com/kai489646859-netizen/Yingyu/releases/tag/android-v1.9.6) |
| Windows | 0.5.8 | Windows 10/11 x64 | [Windows release](https://github.com/kai489646859-netizen/Yingyu/releases/tag/windows-v0.5.8) |

Both public releases have been used on real hardware. Compatibility can still vary with the server, reverse proxy, network, media, decoder, GPU driver, refresh rate and display.

## Highlights

- Multiple Emby servers/accounts, library browsing, movie/series details and season/episode selection.
- Continue watching, favorite/watched state and local pending progress synchronization.
- Built-in mpv original-file playback, seeking, speed, chapters, audio and subtitles.
- STRM, redirect/reverse-proxy and ISO/BDMV playlist/title compatibility within documented boundaries.
- Android phone/tablet layouts and touch gestures; Windows desktop window, mouse and keyboard interaction.
- Redacted diagnostic logs, matching source archives, debugging symbols and SHA-256 files for releases.

## Important boundaries

Yingyu does not provide media, subtitles, servers or accounts. Use only services and content you are authorized to access.

HDR/Dolby identification or compatibility processing is not Dolby certification and does not guarantee native signal output, every profile or complete enhancement-layer presentation. ISO/BDMV playlist support is not the same as complete Blu-ray menus or BD-J.
