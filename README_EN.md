# Yingyu-Theater

An independent Emby client for Android phones and tablets and Windows PCs. Browse and search your own library, resume watching and play original files with mpv.

| Platform | Download | Requirements |
| --- | --- | --- |
| Android | [0.0.2 APK](https://github.com/kai489646859-netizen/Yingyu-Theater/releases/download/android-formal-v0.0.2/Yingyu-0.0.2.apk) | Android 8.0+ |
| Windows | [0.0.2 EXE](https://github.com/kai489646859-netizen/Yingyu-Theater/releases/download/android-formal-v0.0.2/Yingyu-Setup-x64-0.0.2.exe) | Windows 10 / 11, x64 |

Features include multiple servers and accounts, watch progress, playback speed, chapters, audio and subtitle selection, and an optional theater layout. [Official releases](https://github.com/kai489646859-netizen/Yingyu-Theater/releases) contain installation notes, checksums, source archives and debug symbols.
