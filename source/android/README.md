# Yingyu Android source snapshot

This is the directly browsable application-layer snapshot for **Yingyu Android 2.2.4 / code253**.

Included:

- `lib/`: Flutter application, account, library, playback and UI source.
- `android/`: Android host, Java bridge and bounded native integration source.
- `test/`: application, regression and host-scenario tests retained by the release.
- `pubspec.yaml`, `pubspec.lock` and analysis metadata.

Large pinned upstream dependency trees, generated build products, release evidence, binaries, symbols and signing material are intentionally excluded from Git history. The authoritative complete archive is `Yingyu-2.2.4-source.zip` on the [Android 2.2.4 release](https://github.com/kai489646859-netizen/Yingyu/releases/tag/android-v2.2.4); its SHA-256 is published on the same page.
