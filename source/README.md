# Source snapshots

This directory makes the application-layer source for the current public releases directly browsable on GitHub.

- [`android/`](android/README.md): Android 1.9.6 / code224 Flutter, Android host and test source.
- [`windows/`](windows/README.md): Windows 0.5.8 Runtime, Patcher, native integration and packaging source.

Large fixed upstream dependency trees, build evidence, release payloads, binaries and debugging symbols are intentionally not stored in Git history. The complete source and corresponding-source archives remain attached to each GitHub Release together with SHA-256 checksums.

The snapshots contain no signing keys, accounts, access tokens, private media addresses or user logs.
