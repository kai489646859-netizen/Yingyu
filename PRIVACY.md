# Privacy

Yingyu is a third-party client for a server chosen by the user. It does not provide an Emby account, server or media library.

## Data handled by the application

Depending on the platform and enabled features, Yingyu may store locally:

- server address and account/session information required to reconnect;
- application settings, theme and playback preferences;
- cached artwork, metadata and optional media cache;
- local watch progress waiting to be synchronized;
- redacted diagnostic logs and crash/playback state.

The application communicates with servers and media URLs selected or returned by the user's configured service. Optional subtitle, metadata or update features may contact their documented providers when used.

## Telemetry

The public releases do not rely on a project-operated analytics service for advertising profiles. Diagnostic logs are kept locally unless the user chooses to export and share them. Third-party servers, operating systems and network providers may apply their own logging and privacy policies.

## Logs and issue reports

Automatic redaction cannot guarantee removal of every private value. Before posting a log or screenshot publicly, remove server addresses, private domains, usernames, tokens, API keys, full file paths, media URLs and media titles you do not want to disclose.

## Updating and removing data

Cover-installing an update is intended to preserve accounts, settings, progress and caches. Uninstall behavior varies by platform and user choice. Back up important settings before changing or removing an installation.

Questions about privacy can be opened as a Discussion. Security-sensitive reports must follow [`SECURITY.md`](SECURITY.md).
