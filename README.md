## 功能

- **媒体库**　管理多个 Emby 服务器和账号，浏览电影、剧集和分集，查看收藏与观看进度。
- **播放**　使用 MPV 播放原文件，支持继续观看、倍速、章节、音轨和字幕切换，以及兼容的 STRM 和 ISO/BDMV 播放路径。
- **放映厅**　手机、平板和电脑有各自的布局，可切换放映厅主题。Windows 可查看当前画面输出，并按输出条件选择画质预设。

## 安装

安装对应平台的版本，打开应用并添加你有权访问的 Emby 服务器。已有同一安装线可直接覆盖。Windows 请先关闭播放器再运行安装器，系统可能提示「未知发布者」。SHA-256、源码与调试符号见各版本的发行页。仓库改名后，如应用内未发现更新，请从上表下载并覆盖安装。
