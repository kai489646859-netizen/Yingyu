## 说明

映屿用于浏览和播放你有权访问的 Emby 媒体库。Android 版面向手机和平板，Windows 版支持窗口、鼠标和键盘操作。两端均使用 MPV 播放原文件。

- **媒体库**　管理多个服务器和账号，搜索影片、剧集和演员，浏览收藏、分集与片源版本。
- **观看记录**　查看续播位置和已看状态，支持按服务器标记跳过片头、片尾及自动连播。
- **播放控制**　支持倍速、章节、音轨和字幕切换，以及兼容的 STRM 和 ISO/BDMV 播放路径。HDR 和杜比视界的处理取决于片源、系统和显示设备。
- **放映厅**　手机、平板和 Windows 均有可切换的放映厅布局。Windows 可查看当前画面输出，并根据输出方式使用画质预设。

## 使用说明

1. 下载并安装对应版本。使用相同应用身份和签名的旧版可直接覆盖升级。Windows 升级前先关闭播放器。安装器未签名，系统可能提示「未知发布者」。
2. 打开映屿，添加你有权访问的 Emby 服务器地址，并使用该服务器的账号登录。
3. 从首页、媒体库或搜索结果打开影片。剧集可在详情页选季、选集及切换片源。放映厅可在外观设置中切换。
