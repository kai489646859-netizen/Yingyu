# Security policy

## Supported releases

Security fixes are evaluated for the latest public Android and Windows releases. Older releases may be used for comparison but are not guaranteed to receive fixes.

## Reporting a vulnerability

Do not open a public Issue for authentication, token exposure, path traversal, unsafe update, media URL disclosure or another security-sensitive problem.

Use GitHub's **Report a vulnerability** / private security advisory feature for this repository. Include the affected platform and version, impact, minimal reproduction steps and a redacted log if needed.

Never submit passwords, access tokens, API keys, private domains, full media URLs, complete file paths or private media screenshots. Replace them with stable placeholders while preserving the structure needed to reproduce the issue.

You should receive an initial acknowledgement after the report is reviewed. Public disclosure should wait until a fix or mitigation is available.

This policy is not a bug bounty promise and does not authorize access to systems, accounts or media that you do not own or have permission to test.
